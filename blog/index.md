<p>This is an anonymous diary of my first project built together with an AI coding agent. The project was an internal architect program's capstone: AMALend, an agentic cash-flow lending demo on Azure, built with GitHub Copilot CLI between October 26 and November 17, 2026. It is written for people about to try agent-assisted development for the first time, so you can live through the stuck moments before you hit them yourself. Each entry covers one day (or a few quiet days together): what I set out to do, how I asked the agent, where things went sideways, how I got past it, and one takeaway you can reuse as is. Dropped attempts, wrong turns and my own mistakes are left in on purpose; that is where most of the learning was. Every entry is published in English and Korean.</p>

<p lang="ko">AI 코딩 에이전트와 처음으로 함께 개발해 본 과정을 날짜순으로 적은 익명 일지입니다. 사내 아키텍트 과정의 캡스톤 과제로 AMALend(Azure 위의 에이전트 기반 현금흐름 대출 데모)를 2026년 10월 26일부터 11월 17일까지 GitHub Copilot CLI와 함께 만들었습니다. 에이전트와 처음 개발해 보려는 분이 "나도 여기서 막히겠구나, 이렇게 넘어가면 되겠구나"를 미리 겪어 볼 수 있도록 썼습니다. 한 편마다 하려던 일, 에이전트에게 맡긴 방식, 어긋난 지점, 넘어간 방법, 그리고 그대로 가져다 쓸 수 있는 교훈 한 줄을 담았습니다. 접은 시도와 헛디딘 일, 제 실수도 일부러 그대로 남겼습니다. 배운 건 대부분 거기서 나왔거든요. 모든 글은 영어와 한국어로 함께 올립니다.</p>
