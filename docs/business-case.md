# 비즈니스 케이스

원문 과제(Case Study 18)의 사업 목표를 이 데모가 측정한 값과 나란히 놓고, **무엇을 보였고 무엇을 아직 보이지 못했는지** 구분한다. 계산에 쓴 가정은 모두 밝힌다.

> **목표 달성 주장이 아니다.** 데모는 Mock API(마이데이터·홈택스·PG 대역)와 합성 셀러 데이터로 동작한다. 아래 측정값은 시스템의 자동화 구간이 목표를 막지 않는다는 근거일 뿐이고, 비용 60% 절감·48시간 처리·신용비용 100bp 절감을 달성했다는 뜻이 아니다. 실제 효과는 운영 전환 뒤 파일럿에서 잰다(아래 [파일럿에서 잴 것](#파일럿에서-잴-것)).

## 문제와 이해관계자

- **문제:** 고객은 재무제표는 없지만 은행 거래·세금 신고·결제 플랫폼 흐름 같은 디지털 기록이 풍부한 소기업이다. 심사는 여전히 대형 차주용 수작업 재무제표 분석이라 소액 대출은 취급 비용 대비 수익이 나지 않고, 처리에 2주가 걸리며, 부실 경보는 채무불이행 시점에야 온다.
- **경영진 후원자:** 최고사업책임자(CBO, 대출자산 성장·수익성)와 최고리스크책임자(CRO, 신용비용·통제)가 공동 추진한다. 이 설계가 에이전트에게 결정권을 주지 않고 결정론 정책 엔진과 심사역이 결정하게 한 것은 CRO의 통제 요구를 먼저 충족하기 위해서다([ADR-003](adr/ADR-003-deterministic-policy.md)).
- **제약:** 동의 범위·목적·보존 기간 안에서만 데이터를 쓴다. 자동화된 결정에 설명과 이의 경로가 있어야 한다. 국내 처리 요구가 있다(모델 처리 위치는 [ADR-002](adr/ADR-002-model-deployment.md)의 잔여 위험).

## 목표와 데모 증거

| 원문 목표 | 데모가 재는 것 | 측정값(합성 데이터) | 판단 |
|---|---|---|---|
| 소액 대출 취급 비용 60% 절감 | 신청 1건의 AI 비용 + 인프라 고정비 분담 | 월 1,000건 기준 약 $0.88/건(아래 계산) | 기술 비용은 작다는 근거. **심사역 검토 인건비·운영 비용은 재지 않아** 60% 절감 여부는 미검증 |
| 처리 시간 2주 → 48시간 | 접수 → 심사역 대기열 도착 | p95 1.2분(n=24), 게이트웨이 경로 p95 1.8분(n=48) | 자동화 구간은 48시간 예산의 0.1% 미만. **심사역 검토·자료 보완·실제 기관 API 지연은 빠져** 처리 시간 목표는 미검증 |
| 채무불이행 60~90일 전 조기 경보 | 첫 경보 → 합성 연체일 | 평균 리드 70.5~71.7일(양성 경로 2~3건), 재생 실측 66~67일 | 범위 안이지만 **연체가 나도록 설계한 합성 시나리오**다. 실제 부도 이력으로 백테스트하지 않았다 |
| 신용비용 100bp 이상 절감 | 직접 측정 불가 | 조기경보 precision·recall 1.000(탐지기 단독 precision 0.500) | 간접 근거만. 경보 뒤 재조정·회수 성과는 재지 않았다 |
| 대출자산 3억~5억 달러 확대 | 측정 범위 밖 | — | 사업 계획 수치. 데모로 검증할 수 없다 |

출처: SLO1은 `ops/reports/load-20261102110233/report.md` 1장, 게이트웨이 경로는 [비용 모델](cost-model.md#게이트웨이-경로-건당-ai-비용), 조기경보는 `eval/reports/job-eval-9imbutm/report.md` 4장, 재생 실측은 [운영 실행 기록](runbook/deploy-history.md).

## 단위 경제(건당 USD 6,000 대출)

원문은 "건당 6,000달러 대출에서도 수익성을 확보하는 대출기관"을 겨냥한다. 아래는 원문 수치와 명시한 가정만으로 한 산술이다.

| 항목 | 값 | 근거 |
|---|---|---|
| 수작업 취급 원가(가정) | $3,500/건 — 대출액의 58% | Mills & McCarthy(HBS Working Paper 15-004)의 소상공인 대출 처리 원가 $3,000~4,000 중간값, `src/opsmetrics/cost.py`의 `MANUAL_USD` |
| 60% 절감 시 목표 원가 | $1,400/건 이하 | $3,500 × 0.4 |
| 데모 기술 비용(월 1,000건) | 약 $0.88/건 | 건당 AI $0.0939(게이트웨이 경로) + 월 고정비 약 $788 ÷ 1,000. 고정비 = 측정 $304.73 + 측정 뒤 추가된 APIM 약 $51·Functions always ready 약 $62·App Gateway WAF v2 약 $370. 측정 시점이 다른 값을 더한 계산값 |
| 남는 예산 | 약 $1,399/건 | 심사역 검토·운영·조달 비용이 이 안에 들어와야 한다. **이 부분이 비용 목표의 실제 승부처이고 데모는 재지 않았다** |
| 신용비용 100bp의 가치 | 대출 1건 연 $60, 자산 3억~5억 달러면 연 $3M~5M | $6,000 × 1%, $300M~500M × 1% |

- 기술 비용은 물량에 민감하다: 같은 계산으로 월 100건이면 약 $8.0/건, 10,000건이면 약 $0.17/건이다. 대부분 고정비(App Gateway·Service Bus Premium 등)라 물량이 늘면 빠르게 준다([비용 모델](cost-model.md)).
- 2026-11-07 분석가를 `gpt-5.6-sol`로 바꾼 뒤 재측정한 건당 AI 비용은 $0.0738(n=10)로, 위 계산의 $0.0939보다 낮다. 위 계산은 보수적으로 $0.0939를 그대로 쓴다([비용 모델](cost-model.md#게이트웨이-경로-건당-ai-비용)).
- 수작업 원가는 미국 문헌값이다. 실제 원가는 대출기관의 활동기준원가(ABC)로 바꿔 넣어야 한다.

## 미추진 시 비용

- **시장:** 원문은 핀테크가 이미 거래 흐름으로 심사하고 오픈뱅킹 적용 범위가 매달 넓어진다고 본다. 수작업 심사를 유지하면 원문의 3억~5억 달러 자산 확대 기회를 잃는다.
- **신용비용:** 경보가 부도 시점에 오는 구조를 그대로 두면, 위 산술로 자산 3억~5억 달러 기준 연 $3M~5M(100bp)의 절감 기회를 놓친다.
- **원가 구조:** 수작업 원가 가정($3,500)이면 $6,000 대출은 취급만으로 대출액의 절반 넘게 쓴다. 이 구조로는 해당 고객군에 들어갈 수 없다.
- 이 세 항목은 원문의 사업 가정에서 나온 값이다. 데모 측정값이 아니다.

## 파일럿에서 잴 것

원문의 성과 지표 다섯 개(취급 건당 비용, 처리 시간, 경보 선행 기간, 신용비용, 대출자산 성장)를 운영 전환 뒤 이렇게 잰다.

| 성과 지표 | 데모에 이미 있는 계측 | 파일럿에서 더할 것 |
|---|---|---|
| 취급 건당 비용 | 건당 AI 토큰 비용·고정비(`ops report`, [비용 모델](cost-model.md)) | 심사역 검토 시간(콘솔 열람 → 결정), 대출기관 ABC 원가 |
| 처리 시간 | 접수 → 심사역 대기 p50/p95(SLO1), 결정 반영 시간 | 실제 기관 API 지연, 자료 보완 왕복, 심사역 결정까지 전체 시간 |
| 경보 선행 기간 | 첫 경보 → 연체일(평가 하네스 4장) | 실제 연체 이력 백테스트, 섀도 모드 운영(경보만 내고 조치 안 함) |
| 신용비용 | 없음 | 경보 군과 대조군의 12개월 손실률 비교 |
| 대출자산 성장 | 없음 | 승인 건수·금액, 기존 심사 대비 승인율 |

## 데모로 보이는 것

- 2분 데모는 "자동화 구간이 몇 분이라 심사역이 같은 날 근거를 보고 결정할 수 있다"를 보인다. 2분 시간 측정은 아직 하지 않았다([리허설 기록](demo/rehearsal.md)).
