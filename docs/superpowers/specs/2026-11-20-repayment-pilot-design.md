# 상환 충당과 비개입 파일럿 설계

수동 대사 우선과 오래된 회차 자동 충당 중 후자를 선택했다. 확인된 동일 대출 출금을 거래 ID로 중복 제거하고 출금일 현재 도래한 회차에만 오래된 순서로 충당한다. 부분납의 납부액·잔액을 표시하고 추심은 잔액 기준으로 검토한다. 완납된 회차의 이력은 유지하고 미발송 제안은 발송하지 않는다. 초과분을 미래 회차에 쓰지 않는다.

정산 예정액은 실제 입금이 아님을 한국어·영어로 설명한다. 별도로 실제 심사 업무시간과 신청·실행 원가를 수집할 수단, 동일 신청에서 마켓 자료의 효과를 분리하는 비개입 비교를 제공한다. 기관 수치는 수집 전까지 미측정으로 둔다. 실제 고객 연락·운영 모델 변경·유료 평가·배포는 제외한다.
