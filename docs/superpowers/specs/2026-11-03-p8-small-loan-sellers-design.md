# P8 소액 대출·온라인 셀러 데이터 설계

상태: 승인(2026-11-03). 앞 단계: P7 콘솔 UI(병합 완료, `8997b5b`).

## 1. 목표

데모 전체를 "온라인 마켓플레이스 셀러의 500만 원 이하 소액 운전자금 대출"로 바꾼다.

- 대출 금액은 50만~500만 원이다.
- 데모·부하·미리보기 신청자는 모두 온라인 셀러다. 오프라인 업종(카페·한식·분식·제과점·편의점)은 남기지 않는다.
- 업종은 10개로 늘린다.

이 스펙의 금액·업종은 원 설계 스펙(`2026-10-31-agentic-cashflow-lending-design.md`)의 데모 수치("매출 3억 원 카페")를 대체한다.

범위 밖: Azure 재배포, 평가 재실행, 과거 기록 문서(`docs/runbook/deploy-history.md`, `docs/demo/rehearsal.md`의 측정 기록, 지난 계획서·스펙) 수정.

## 4. 평가 어려운 적요 뱅크

`HARD_BANK`의 라벨과 개수(라벨마다 4개)는 그대로 두고, 금액을 1/6로 줄인다. 음식점 맥락의 적요는 셀러 맥락으로 바꾼다. 바뀐 적요도 `classify-v1` 규칙 키워드(`급여`·`개인이체`·`임대료`·`대부`·`P2P`·`대출상환`·`국민건강보험`·`대출금`)에 걸리지 않아야 한다. 예: `CJ프레시웨이 물품대금` → `도매꾹 사입대금`, `동원홈푸드 식자재` → `OEM 제조사 생산대금`, `주방보조 월급` → `포장 보조 월급`, `상가 월세` → `물류창고 월세`, `세스코 방역` → `스마트스토어 광고비`.

평가 수치는 Azure에서 다시 돌릴 때 바뀐다. 이미 기록한 P6a 결과는 과거 기록으로 둔다.

## 6. 검증

- 전체 테스트가 통과한다. 금액·업종·ID를 고정한 테스트는 새 값으로 고친다.
- 신청액 3,300,000·as_of 2026-11-02 기준 보정 값(개월, 월평균 유입, DSCR, 완충일수, 변동성, 세무 일치율): healthy (12, 5,360,727, 3.783, 122.2, 0.196, 0.971), mismatch (12, 5,448,246, 4.003, 129.8, 0.199, 0.6), stress (12, 5,089,967, 3.016, 126.4, 0.271, 0.977), thin (4, 6,070,672, 4.357, 51.9, 0.206, 0.0), injection (12, 5,420,065, 3.89, 125.7, 0.191, 0.984). 테스트는 이 값으로 고정한다.
- 정책 판정과 금리 구간이 바뀌지 않는다. 바꾸기 전 기준(as_of 2026-11-01, 데모 신청액 30,000,000·부하 10,000,000, 12개월):
  - `demo-cafe-001`(→`demo-healthy-001`)·`demo-stress-003`·`demo-injection-005`: `eligible`, 구간 A, 한도는 정책 최대.
  - `demo-mismatch-002`: `refer`(R101), 구간 A.
  - `demo-thin-004`: `ineligible`(R001·R101·R104).
  - 부하 격자: 원형별 판정 조합은 healthy `eligible` 또는 `refer`(R104), mismatch `refer`(R101[+R104]), stress `eligible` 또는 `refer`(R104), thin `ineligible`(R001·R101[+R104]). R104는 업력 8개월 칸에만 붙는다.
- 사후 흐름: STACKING(`demo-healthy-001`)은 `default_on`이 생기고(기준 2027-01-20, ±7일 허용), STABLE은 생기지 않는다.
- 부하 격자 균형(원형×업종 2명, 업종 8명, 지역·업력 16명)을 테스트로 고정한다.
- 정책 한도: 신청액 5,000,000 초과는 `amount_exceeds_policy`, 한도 계산은 `min(월평균 유입×1.5, 5,000,000)`.
- 미리보기 화면을 띄워 금액·업종이 보이는지 확인한다.
- 템플릿 CSP 규칙(인라인 `style`·`<script>` 금지)은 그대로다.
