# App Gateway WAF v2 진입점 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 심사역 콘솔 앞에 Application Gateway WAF v2(Prevention, OWASP DRS 2.1, 운영자 IP만 허용)를 상시 두고, 콘솔은 내부 Container Apps 환경(`cae-int`)으로 옮겨 인터넷에서 직접 닿지 않게 한다.

**Architecture:** 공용 IP(`pip-agw-*`, DNS 레이블) → App Gateway(`agw-*`, `snet-appgw` 192.168.7.0/24, WAF 정책 `waf-*`) → HTTPS(호스트 이름은 백엔드 FQDN) → `ca-console`(cae-int, 내부 전용). TLS 인증서는 ops가 메모리에서 만든 자체 서명 PFX를 제어면 ARM PUT으로 Key Vault 비밀(`appgw-console`)에 쓰고, App Gateway는 사용자 할당 ID(`id-appgw-*`)로 Private Endpoint를 거쳐 읽는다. 인증서 비밀 ID(`APPGW_CERT_SECRET_ID`)가 없으면 공용 IP만 만들고 게이트웨이는 만들지 않는다(첫 `window open`이 두 번 프로비저닝). `cae-web`·`snet-apps-web`은 지운다.

**Tech Stack:** Bicep(Microsoft.Network 2024-05-01, Insights diagnosticSettings 2021-05-01-preview), Python 3.12, cryptography(>=42), pytest, PSRule 펼침(infra 테스트), Azure Monitor(AGWAccessLogs·AGWFirewallLogs).

**Spec:** `docs/superpowers/specs/2026-11-06-appgw-waf-design.md`

```python
"""App Gateway WAF v2 콘솔 진입점 IaC: 공용 IP, WAF 정책(Prevention, 운영자 IP만), 게이트웨이, 진단, 최소 권한."""
import json
import re
import shutil
import subprocess
from pathlib import Path

import pytest

INFRA = Path(__file__).resolve().parents[2] / "infra"
BICEP = shutil.which("bicep") or str(Path.home() / ".azure" / "bin" / "bicep.exe")
AGW = "Microsoft.Network/applicationGateways"
WAF = "Microsoft.Network/ApplicationGatewayWebApplicationFirewallPolicies"
PIP = "Microsoft.Network/publicIPAddresses"
CERT = "https://kvamatest.vault.azure.net/secrets/appgw-console"


def _compile(path: Path) -> dict:
    proc = subprocess.run([BICEP, "build", str(path), "--stdout"], capture_output=True, text=True,
                          encoding="utf-8", check=True)
    return json.loads(proc.stdout)


def _resources(template: dict) -> list[dict]:
    res = template["resources"]
    return list(res.values()) if isinstance(res, dict) else res


def _by_name(items: list[dict]) -> dict[str, dict]:
    return {i["name"]: i["properties"] for i in items}


def test_public_ip_always_exists_with_dns_label(closed):
    # 인증서 CN이 될 DNS 이름은 게이트웨이보다 먼저(첫 프로비저닝에서) 있어야 합니다.
    pip = closed.one(PIP, "pip-agw-amatest")
    assert pip["sku"]["name"] == "Standard"
    props = pip["properties"]
    assert props["publicIPAllocationMethod"] == "Static"
    assert props["publicIPAddressVersion"] == "IPv4"
    assert re.fullmatch(r"amatest-[0-9a-z]{13}", props["dnsSettings"]["domainNameLabel"])


def test_gateway_waits_for_certificate(closed):
    assert closed.of_type(AGW) == []
    assert closed.of_type(WAF) == []


def test_gateway_sku_identity_and_tls(opened):
    gw = opened.one(AGW, "agw-amatest")
    props = gw["properties"]
    assert props["sku"] == {"name": "WAF_v2", "tier": "WAF_v2"}
    assert props["autoscaleConfiguration"] == {"minCapacity": 0, "maxCapacity": 2}
    assert gw["identity"]["type"] == "UserAssigned"
    assert list(gw["identity"]["userAssignedIdentities"]) == [
        next(i["id"] for i in opened.of_type("Microsoft.ManagedIdentity/userAssignedIdentities")
             if i["name"] == "id-appgw-amatest")]
    assert props["sslCertificates"] == [{"name": "console-tls", "properties": {"keyVaultSecretId": CERT}}]
    assert props["sslPolicy"] == {"policyType": "Predefined", "policyName": "AppGwSslPolicy20220101"}
    [ipconf] = props["gatewayIPConfigurations"]
    assert ipconf["properties"]["subnet"]["id"].endswith("/subnets/snet-appgw")
    [frontend] = props["frontendIPConfigurations"]
    assert frontend["properties"]["publicIPAddress"]["id"].endswith("/pip-agw-amatest")
    assert props["firewallPolicy"]["id"].endswith("/waf-amatest")


def test_gateway_routes_https_to_console_and_redirects_http(opened):
    props = opened.one(AGW, "agw-amatest")["properties"]
    listeners = _by_name(props["httpListeners"])
    assert set(listeners) == {"https", "http"}
    assert listeners["https"]["protocol"] == "Https"
    assert listeners["https"]["frontendPort"]["id"].endswith("/frontendPorts/port-443")
    assert listeners["https"]["sslCertificate"]["id"].endswith("/sslCertificates/console-tls")
    assert listeners["http"]["protocol"] == "Http"
    assert listeners["http"]["frontendPort"]["id"].endswith("/frontendPorts/port-80")

    redirect = _by_name(props["redirectConfigurations"])["http-to-https"]
    assert redirect["redirectType"] == "Permanent"
    assert redirect["includePath"] is True and redirect["includeQueryString"] is True
    assert redirect["targetListener"]["id"].endswith("/httpListeners/https")

    rules = _by_name(props["requestRoutingRules"])
```

```python
"""콘솔 App Gateway의 자체 서명 TLS 인증서(스펙 §4).

MCAPS 정책이 Key Vault 공용 접근을 막으므로 데이터 평면(az keyvault certificate) 대신 제어면 ARM PUT으로
비밀 appgw-console을 씁니다. PFX는 메모리에서만 만들고, 요청 본문 임시 파일은 바로 지웁니다.
App Gateway는 버전 없는 비밀 ID를 4시간마다 다시 읽으므로 갱신은 다시 프로비저닝하지 않아도 반영됩니다.
"""
from __future__ import annotations

import base64
import datetime as dt
import json
from typing import Callable

from cryptography import x509
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import rsa
from cryptography.hazmat.primitives.serialization import pkcs12
from cryptography.x509.oid import ExtendedKeyUsageOID, NameOID

from ops.azcli import OpsError, Runner, is_not_found, rest_put, subscription_runner
from ops.azdenv import get_env, set_env

SECRET_NAME = "appgw-console"
API_VERSION = "2023-07-01"
VALID_DAYS = 365
RENEW_BEFORE_DAYS = 30
ENV_KEY = "APPGW_CERT_SECRET_ID"


def _utcnow() -> dt.datetime:
    return dt.datetime.now(dt.timezone.utc)


def build_pfx(fqdn: str, now: dt.datetime) -> tuple[bytes, dt.datetime, dt.datetime]:
    """CN·SAN이 fqdn인 자체 서명 서버 인증서와 키를 암호 없는 PFX로 만듭니다."""
    key = rsa.generate_private_key(public_exponent=65537, key_size=2048)
    name = x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, fqdn)])
    not_before = now - dt.timedelta(minutes=5)
    not_after = now + dt.timedelta(days=VALID_DAYS)
    cert = (
        x509.CertificateBuilder()
        .subject_name(name)
        .issuer_name(name)
        .public_key(key.public_key())
        .serial_number(x509.random_serial_number())
        .not_valid_before(not_before)
        .not_valid_after(not_after)
        .add_extension(x509.SubjectAlternativeName([x509.DNSName(fqdn)]), critical=False)
        .add_extension(x509.BasicConstraints(ca=False, path_length=None), critical=True)
        .add_extension(x509.ExtendedKeyUsage([ExtendedKeyUsageOID.SERVER_AUTH]), critical=False)
        .sign(key, hashes.SHA256())
    )
    pfx = pkcs12.serialize_key_and_certificates(fqdn.encode(), key, cert, None, serialization.NoEncryption())
    return pfx, not_before, not_after


def _needs_new_cert(az: Runner, url: str, now: dt.datetime) -> bool:
    try:
        secret = json.loads(az(["az", "rest", "--method", "get", "--url", url]) or "{}")
    except OpsError as err:
        if is_not_found(err):
            return True
        raise
    exp = secret.get("properties", {}).get("attributes", {}).get("exp")
    if exp is None:
        return True
    return dt.datetime.fromtimestamp(exp, dt.timezone.utc) - now < dt.timedelta(days=RENEW_BEFORE_DAYS)


def ensure_console_cert(runner: Runner, now: Callable[[], dt.datetime] = _utcnow) -> bool:
    """인증서 비밀이 없거나 만료 30일 전이면 새로 쓰고, azd 환경의 APPGW_CERT_SECRET_ID를 맞춥니다.

    환경 값이 바뀌었으면(게이트웨이를 만들려면 다시 프로비저닝해야 함) True를 돌려줍니다.
    """
    env = get_env(runner)
    fqdn, kv_name, kv_uri = env.get("APPGW_FQDN"), env.get("KEYVAULT_NAME"), env.get("KEYVAULT_URI")
    if not (fqdn and kv_name and kv_uri):
        raise OpsError("azd 환경에 APPGW_FQDN·KEYVAULT_NAME·KEYVAULT_URI가 없습니다. 먼저 `azd provision`을 실행하세요.")
    az = subscription_runner(runner, env)
    kv_id = az(["az", "keyvault", "show", "--name", kv_name, "--query", "id", "-o", "tsv"]).strip()
    url = f"https://management.azure.com{kv_id}/secrets/{SECRET_NAME}?api-version={API_VERSION}"
    current = now()
    if _needs_new_cert(az, url, current):
        pfx, not_before, not_after = build_pfx(fqdn, current)
        rest_put(az, url, {"properties": {
            "value": base64.b64encode(pfx).decode("ascii"),
            "contentType": "application/x-pkcs12",
            "attributes": {"enabled": True, "nbf": int(not_before.timestamp()), "exp": int(not_after.timestamp())},
        }})
    secret_id = f"{kv_uri.rstrip('/')}/secrets/{SECRET_NAME}"
    if env.get(ENV_KEY) == secret_id:
        return False
    set_env(runner, ENV_KEY, secret_id)
    return True
```

```markdown
# ADR-011: 콘솔 진입점을 Application Gateway WAF v2로

## 상태
채택(2026-11-06) · as-built. [ADR-006](ADR-006-two-container-apps-environments.md)의 "외부 환경에 콘솔" 부분을 대체한다.

## 맥락
심사역 콘솔은 외부 Container Apps 환경(`cae-web`)의 ingress IP 허용 목록과 Entra 로그인으로만 막혀 있었다. 인터넷 진입점에 L7 방어(OWASP 규칙, 요청 본문 검사)와 진입 로그가 없었고, 운영 아키텍처 문서에는 App Gateway WAF v2를 "운영 전환 시 구축"으로만 적어 두었다. 이번에 데모에서도 실제로 구축한다(스펙 `docs/superpowers/specs/2026-11-06-appgw-waf-design.md`).

## 결정
- 공용 IP(`pip-agw-*`, DNS 레이블) → Application Gateway WAF_v2(`agw-*`, `snet-appgw` 192.168.7.0/24, 자동 확장 0–2) → HTTPS → 내부 환경 `cae-int`의 `ca-console`. `cae-web`과 `snet-apps-web`은 지운다.
- WAF 정책(`waf-*`): Prevention, OWASP DRS 2.1, 사용자 지정 규칙 `allowOperatorOnly`(운영자 IP가 아니면 차단, 비면 TEST-NET만 허용해 fail-closed). 운영자 IP는 `CONSOLE_IP`(`window open`이 설정)에서 온다.
- TLS: 자체 서명 인증서. MCAPS 정책이 Key Vault 공용 접근을 막으므로 ops가 PFX를 메모리에서 만들어 제어면 ARM PUT으로 Key Vault 비밀 `appgw-console`에 쓰고(`src/ops/appgw_cert.py`), 게이트웨이는 사용자 할당 ID `id-appgw-*`(Key Vault Secrets User)로 Private Endpoint를 거쳐 읽는다.
- 인증서 비밀 ID(`APPGW_CERT_SECRET_ID`)가 없으면 공용 IP만 만든다. 첫 `window open`은 프로비저닝 → 인증서 → 두 번째 프로비저닝으로 게이트웨이를 만든다.
- Easy Auth는 리디렉션 URI를 게이트웨이 이름으로 두고, `forwardProxy`(Custom, `X-Original-Host`)로 원래 호스트를 읽는다. HTTP는 HTTPS로 영구 리디렉션한다. 진입·WAF 로그는 Log Analytics(`AGWAccessLogs`, `AGWFirewallLogs`)로 보낸다.

## 검토한 대안
| 대안 | 장점 | 기각 이유 |
|---|---|---|
| 기존 ingress IP 허용 목록 유지 | 비용 0 | L7 방어·진입 로그 없음. 과제의 "앞단 WAF" 요구 미충족 |
| Front Door Premium + WAF | 전역 엣지, 관리형 인증서 | Private Link 원본에 Premium 필요(월 고정비가 더 큼), 내부 ACA 원본 구성 복잡 |
| Key Vault 인증서 개체(`az keyvault certificate create`) | 갱신 자동화 | 데이터 평면이라 공용 접근이 막힌 Key Vault에 운영자 PC에서 닿지 않음 |
| 인증서를 Bicep 파라미터로 직접 전달 | 단계 하나 | PFX가 배포 기록에 남음. 비밀 노출 |
| 운영 시간에만 게이트웨이 생성 | 비용 절감 | 생성에 수십 분, 상시 진입점이라는 요구와 충돌 |

## 결과
- 인터넷에서 콘솔에 닿는 길은 게이트웨이 하나뿐이고, 운영자 IP 밖 요청은 WAF가 403으로 막는다. 콘솔 컨테이너는 VNet 밖에서 직접 닿지 않는다.
- 월 고정비가 약 $370 늘어난다([비용 모델](../cost-model.md)).
- 자체 서명이라 브라우저 경고가 뜬다. 운영 전환 시 공인 CA 인증서와 사용자 도메인으로 바꾼다.
- 첫 `window open`이 두 번 프로비저닝해 더 오래 걸린다. 인증서 갱신(만료 30일 전)은 `window open`이 처리하고, 게이트웨이는 버전 없는 비밀 ID를 주기적으로 다시 읽는다.

## 재검토 조건
- 사용자 도메인·공인 인증서가 생기면 자체 서명과 브라우저 경고를 없앤다.
- DRS 2.1 오탐이 콘솔 업무를 막으면 해당 규칙만 정책 제외로 둔다.
- 여러 지역·전역 사용자가 생기면 Front Door를 다시 검토한다.
```
