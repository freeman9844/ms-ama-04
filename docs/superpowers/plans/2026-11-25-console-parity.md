# 영어·USD 심사 콘솔 복원 구현 계획

> 작업자는 `subagent-driven-development` 또는 `executing-plans`로 항목별 실행한다.

**목표:** 영어 기본 USD 신청에서 기존 심사 콘솔과 같은 8개 탭, 분석 패널, 결정 동선과 안전한 검토 이력을 제공한다.

**구조:** 템플릿과 데이터 표시 모델을 공유한다. 통화와 정책은 문서의 상품 계약으로 선택하고 언어는 기존 i18n으로 선택한다. 기존 핫픽스가 있는 `.worktrees\english-usd`를 기준으로 한다.

**기술:** Python, FastAPI, Jinja, pytest, 브라우저 DOM 검사.

**설계:** `docs\superpowers\specs\2026-11-25-console-parity-design.md`

## 공통 제약

- `3ba299b`를 기능 대조 기준으로 삼는다. USD는 센트 정수 유지, 읽기 화면은 `$5000`, 결정 입력은 소수 보존. 가짜 KRW 필드·환산 금지.
- 정책·권한·마스킹·의견 발행 기준은 그대로 둔다. 운영 쓰기·데이터 복구·배포·푸시는 범위 밖이다.
- 테스트 명령은 USD 작업트리에서 `..\..\.venv\Scripts\python.exe -m pytest`로 실행한다.

## 검토 초점

금액 0과 결측, 두 통화 계약 혼용, 반려된 검토자 원문 노출, 동의 철회·감사자 접근, 모바일 영문 레이블 겹침을 각 소유 작업에서 확인한다.
