[Drawing contract — core principles]
1. Vertical flow, top to bottom: (1) external contact & network management -> (2) web/app tier and related resources -> (3) data (bottom).
2. The resource receiving external traffic sits directly below the entry card on the same vertical axis. Never receive from above via a card placed to the left.
3. Lines run top to bottom, never tangle across tiers, never pass over card bodies. One flow direction per drawing.
4. The spec's object and connection lists are complete. No additions, removals or duplicates. Every card shows its quantity (xN).
5. Professional Azure architecture diagram style: white background, official Azure icons, thin-bordered cards, nested frames (region, VNet, subnets), a numbered badge and capsule label on every line, a legend.
6. All text must be crisp and spelled exactly, in ENGLISH only (no Korean characters). No ellipses.
